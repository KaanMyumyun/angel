# Тестове

```bash
mvn test
```

Тестовете **не изискват инсталиран MySQL** — интеграционните използват H2 в режим
MySQL, създадена от **същия** файл `database/01_schema.sql`, който се импортира и в
реалната база. Така схемата се проверява при всяко пускане на тестовете.

## Сценарии, които си струва да се покажат при защита

**Нормален случай** — продажба на 4 бр. от лекарство с две партиди:
изчерпва се първо партидата с по-ранен срок.

**Граничен случай** — партида, чийто срок изтича точно днес, все още е валидна;
партида, изтекла вчера, не се предлага за продажба.

**Негативен случай** — продажба на 999 бр. при налични 60:
`InsufficientStockException`, а в базата **не се записва нищо** — нито продажба,
нито артикули, нито движения (`insufficientStockRollsBackCompletely`).

**Атака** — търсене с текст `'; DROP TABLE medicines; --`:
таблицата остава непокътната, защото текстът се подава като параметър
(`searchIsSafeAgainstSqlInjection`).

**Атака** — лекарство с име `<script>alert('xss')</script>`:
на екрана се извежда екранирано, скриптът не се изпълнява
(`outputIsEscapedAgainstXss`).
