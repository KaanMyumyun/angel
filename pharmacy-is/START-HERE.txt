==========================================================
  ИНФОРМАЦИОННА СИСТЕМА ЗА АПТЕКА — КАК ДА Я ПУСНЕШ
  (инструкциите са за Windows)
==========================================================

Трябват ти три неща:

   1. Git                      ->  провери с:  git --version
   2. Java 17 или по-нова      ->  провери с:  java -version
   3. MySQL 8 или по-нова      ->  провери с:  mysql --version

Maven НЕ ти трябва — проектът носи свой собствен.

ВАЖНО: изпълнявай командите в Command Prompt (cmd), НЕ в
PowerShell. В PowerShell знакът "<" не работи и Стъпка 3 ще
гръмне. Натисни Win+R, напиши cmd и Enter.


----------------------------------------------------------
СТЪПКА 1.  Свали кода
----------------------------------------------------------

   git clone https://github.com/KaanMyumyun/angel.git
   cd angel\pharmacy-is

Нямаш Git? Отвори адреса в браузъра, натисни зеления бутон
"Code" -> "Download ZIP", разархивирай и влез в папката
angel-main\pharmacy-is.


----------------------------------------------------------
СТЪПКА 2.  Пусни MySQL сървъра
----------------------------------------------------------

   XAMPP:      отвори XAMPP Control Panel -> Start при MySQL
   Услуга:     net start MySQL84
               (номерът зависи от версията: MySQL80, MySQL84...)

Ако "mysql" не се разпознава като команда, значи не е в PATH.
При XAMPP програмата е тук:

   C:\xampp\mysql\bin\mysql.exe

Пиши целия път вместо само "mysql" в командите отдолу.


----------------------------------------------------------
СТЪПКА 3.  Създай базата (само първия път)
----------------------------------------------------------

В Command Prompt, от папката pharmacy-is:

   mysql -u root -p < database\00_create_database.sql

Ще поиска паролата на root за MySQL. При XAMPP root обикновено
е БЕЗ парола — просто натисни Enter.

Това създава база "pharmacy" и потребител "pharmacy_app"
с парола "pharmacy_pass".

- - - - - - - - - - - - - - - - - - - - - - - - - - - - - -
ПО-ЛЕСЕН ВАРИАНТ, ако нещо се запъне на тази стъпка:

Пропусни я изцяло и вместо това отвори с Notepad файла

   src\main\resources\application.properties

намери тези два реда и ги направи така:

   spring.datasource.username=root
   spring.datasource.password=

(ако твоят root има парола, напиши я след знака =)

Приложението ще създаде базата и таблиците само.
- - - - - - - - - - - - - - - - - - - - - - - - - - - - - -


----------------------------------------------------------
СТЪПКА 4.  Стартирай приложението
----------------------------------------------------------

   mvnw.cmd spring-boot:run

Първия път ще тегли библиотеки от интернет — 2-3 минути.
Следващите пъти тръгва за около 5 секунди.

Таблиците и демонстрационните данни се създават АВТОМАТИЧНО
при първото пускане. Не ти трябва нищо друго.

Готово е, когато видиш ред, който свършва с:

   Started PharmacyApplication in ... seconds


----------------------------------------------------------
СТЪПКА 5.  Отвори в браузъра
----------------------------------------------------------

   http://localhost:8080

   Потребител    Парола        Какво вижда
   -----------   -----------   --------------------------------
   manager       manager123    всичко, вкл. справки и печалба
   pharmacist    pharma123     каса, склад, доставки, търсене

==========================================================
  АКО НЕЩО НЕ ТРЪГНЕ
==========================================================

"The '<' operator is reserved for future use"
      Използваш PowerShell. Отвори Command Prompt (cmd).

"'mysql' is not recognized as an internal or external command"
      MySQL не е в PATH. Виж Стъпка 2 — пиши пълния път.

"'git' is not recognized..."
      Нямаш Git. Свали ZIP от GitHub (виж Стъпка 1) или
      инсталирай от https://git-scm.com

"Communications link failure"
      MySQL не е пуснат. Върни се на Стъпка 2.

"Access denied for user 'pharmacy_app'"
      Стъпка 3 не е минала успешно. Пусни я пак и гледай за
      грешка, или използвай по-лесния вариант от Стъпка 3.

"Unknown database 'pharmacy'"
      Стъпка 3 не е изпълнена.

"Port 8080 was already in use"
      Нещо друго заема порта (често Skype или друг сървър).
      Спри го или пусни системата на друг порт:
         mvnw.cmd spring-boot:run -Dspring-boot.run.arguments=--server.port=8081
      Тогава отваряй http://localhost:8081

Вместо кирилица се виждат въпросителни
      Базата е създадена без utf8mb4. Изпълни пак Стъпка 3.

"java: command not found" / "'java' is not recognized"
      Java не е инсталирана или не е в PATH.
      Изтегли от: https://adoptium.net
